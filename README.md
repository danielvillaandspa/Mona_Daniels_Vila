# Daniel’s Villa & Spa

الموقع المنشور: https://danielvillaspa.site/

## تنظيم الملفات

- index.html: محتوى الصفحة والترجمات العربية والعبرية والإنجليزية.
- assets/css/styles.css: تصميم الصفحة والاستجابة لأحجام الشاشات.
- assets/js/app.js: معرض الصور وتبديل اللغات وتفاعلات الصفحة.
- assets/js/analytics.js: إعداد Google Analytics الحالي.
- صور IMG الأصلية: بقيت في مواقعها للحفاظ على روابط الصور الحالية.
- CNAME وملف تحقق Google: ضروريان للدومين وإثبات الملكية.
- .github/workflows/static.yml: نشر الموقع تلقائيًا عند تحديث main.

## المعاينة

شغّل خادم ملفات محليًا من هذا المجلد، مثل python -m http.server 4174، ثم افتح http://localhost:4174.

## النشر والحماية

GitHub Pages يستضيف الموقع، وCloudflare يدير DNS وحماية الزيارات. سجلات البريد الخاصة بـ Hostinger تبقى DNS only. لا تُضف أي مفاتيح سرية إلى ملفات الموقع؛ جميع الملفات المنشورة عامة.

تم فصل الكود دون تغيير محتوى الصفحة أو بيانات التواصل أو ترتيب الصور.
